# 8. 開発の痕跡と関連ソフト

ソースコードのコメントやコメントアウトしたコードは、コンパイルの時点で消えるので、実行ファイルには残りません。この章では、**コンパイルしたあとも残っている開発の痕跡**と、KITACO の他のソフトとの比較をまとめます。

## 8.1 ビルド情報

| 項目 | 値 | 確度 |
|---|---|---|
| デバッグ情報（PDB）のパス | `C:\Users\administrator\Documents\root\Software\i-map関連Win用ソフト\map_creat1.03\map_creat\obj\Debug\fuel_manager.pdb` | 【観測】PE のデバッグディレクトリ（RSDS）。パスは UTF-8 で記録されている |
| ビルド構成 | **Debug** | 【観測】パスの `obj\Debug` と、エディットコンティニュー用のコード（`__ENCAddToList`）があることから |
| ビルド日時 | 2015-01-06 09:35:45 UTC（日本時間 18:35） | 【観測】PE ヘッダの TimeDateStamp。zip 内のファイルの日付とも合う |
| アセンブリのタイトル / 製品名 | `map editor for i-map` | 【観測】 |
| アセンブリの著作権表示 | `Copyright (C)  2008` | 【観測】画面の表示は「(C) 2009」 |

読み取れることは次のとおりです。

- **社内でのプロジェクト名は `map_creat`（map create）**です。
- フォルダ名は `map_creat1.03` ですが、画面の表示は「Version 1.02」です。表示の更新を忘れた可能性があります。
- **デバッグ設定のままビルドして配布**しています。そのため、最適化されておらず、使われていない変数などもそのまま残っています（8.2 節）。
- 開発は 2008 年に始まり、2015 年 1 月にこの版がビルドされたと考えられます。
- フォルダ名「i-map関連**Win用**ソフト」からは、Windows 用ではない i-map 関連のソフト（本体のファームウェアなど）が別に管理されていたことがうかがえます【推測】。
- プロジェクト名「マップ作成」から、もともとは社内でマップを作るための道具を、ユーザー向けに公開したものかもしれません【推測】。

## 8.2 使われていないコード

| 種類 | 内容 | 推測 |
|---|---|---|
| 宣言だけで使われていないフィールド | `time_out` | タイムアウト処理を作るつもりで、実装しなかったか途中で消した。通信が途切れると固まる不具合（[5.4 節](05-quirks-and-bugs.md#54-通信が途切れると固まる)）と合う |
| 同上 | `kijun_x`、`kijun_y`（「基準」座標） | グラフの描画を書き直したときの残り |
| 使われていないローカル変数 | 保存処理の `num3`、`num4 = 1`、読み出し処理の `num2` など | デバッグ設定でビルドしているので残っている |
| 意味のない処理 | 保存処理の最初で、`"0"` を入れた文字列の末尾を 1 文字削って空にしている | 書き直しの名残 |
| 中身が空のイベント処理 | `dgv_CellContentClick`、`Form2_Load`、`Label3_Click`、`Label4_Click`、`Form3_Load`、Form3 の `PictureBox1_Click` | 画面デザイナで部品をダブルクリックすると自動で作られる。VB ではよくある |
| 使われていないフォーム | `Form3`（タイトルは「Form3」のまま、画像のない 201×195 の枠だけ）。どこからも呼ばれていない | 起動時のロゴ画面などを作りかけてやめた |
| コードから使われていない画面部品 | `PictureBox2`（グラフの下、664×14）、`PictureBox3`（グラフの左、39×279） | 目盛りの数字は `Label` の配列 `memori`（目盛り）で描いているので、その背景用か作りかけの名残 |

## 8.3 隠し機能の痕跡はあるか

**見つかりませんでした**【観測】。

- コードが読み込む文字列 126 個はすべて用途がわかっていて、通信に使うのは `m`、`s`、`r`、`/`、`,` だけでした。
- 使われていない通信処理のメソッドもありません。

ただし、コードごと消された機能は、その文字列も含めて実行ファイルに残りません。言えるのは「**このソフトには痕跡が残っていない**」までです。

## 8.4 KITACO の他のソフトとの比較（データロガー）

i-Map の配布ページには「データロガー」用のソフト `Loger.EXE` もあります。これが i-Map と通信するかどうかを確かめました。

| 項目 | 内容 |
|---|---|
| 形式 | UPX で圧縮された zip の自己解凍書庫 |
| 中身 | `Data_manager.exe`（2009-07-13）、`Lap_comp.exe`、CP210x ドライバ、.NET Framework のインストーラ、説明書の PDF 3 つ |
| `Data_manager.exe` | VB.NET 製。タイトルは「Log Viewer Ver1.00」、`Copyright © 2009 KITACO Co.,LTD` |
| 通信速度 | **115200 bps**（i-Map は 38400 bps） |
| 通信の方式 | 改行付きの単語コマンド（`dat_log`、`trans`、ファイル番号など）を送る。PC 側から `r` を確認応答として送る |
| 記録する項目 | 電圧、速度、回転数、温度 A/B、ストローク、O2、アナログ A/B |
| i-Map への言及 | なし |

わかったことは次のとおりです。

- データロガーは **i-Map とは別の機器**（走行データをファイルとして記録するロガー）用のソフトです。i-Map の別機能を使っている公式ソフトではありませんでした【観測】。
- 一方で、作り方が Fuel Manager と共通しています。
  - COM1〜COM20 のメニューがあり、`COM20` を未設定の目印にしている
  - 英語のエラーメッセージ（`Communication device is not connected.` など）が同じ
  - 確認応答に `r` を使う
  
  **同じ開発者（または同じ社内の作り方）**によるものと考えられます【推測】。
