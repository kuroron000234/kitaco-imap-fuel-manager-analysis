# KITACO I-MAP「Fuel Manager」解析レポート

KITACO（キタコ）の燃調コントローラ **i-Map** には、PC でマップを編集する専用ソフト **Fuel Manager v1.02** が付いています。この文書は、そのソフトを静的解析した結果をまとめたものです。扱う内容は次の3つです。

- ソフトの内部構造
- `.fmp` マップファイルの形式
- PC と i-Map の間のシリアル通信プロトコル

> [!IMPORTANT]
> - このリポジトリは個人の解析記録です。株式会社キタコとは関係ありません。
> - KITACO の配布物（実行ファイル、取扱説明書、公式マップデータ）と、デコンパイルしたソースコードは**含めていません**。必要なものは[公式サイト](https://www.kitaco.co.jp/imap)から入手してください。
> - この文書の情報を使って i-Map に書き込む場合は、自己責任でお願いします。取扱説明書には、通信中に電源が切れると本体のメモリや本体が壊れるおそれがあると書かれています。
> - i-Map 本体（ファームウェア）は解析していません。本体側の動作についての記述は、PC ソフトの実装から推測したものです。

## 要点

| 項目 | 内容 |
|---|---|
| 実装 | VB.NET（Visual Studio 2005 世代）、.NET Framework 2.0〜3.5、Windows Forms。難読化なし |
| 物理接続 | Silicon Labs CP210x USB-UART ブリッジ。PC 側からは仮想 COM ポートとして見える |
| 通信設定 | 38400 bps。それ以外は .NET の既定値（8 データビット、パリティなし、1 ストップビット、フロー制御なし） |
| 通信方式 | ASCII テキスト。チェックサム、暗号化、認証はない |
| 読み出し | PC が `m` を送る → i-Map がマップ番号（生のバイト1個）、CSV テキスト、終端の `/` を返す |
| 書き込み | PC が `s` を送る → i-Map が `r` を返す → 回転数の列ごとに「21 個の値 + `/`」を送って `r` を待つ。これを 30 回くり返す |
| マップの形 | 回転数 30 列（500〜15000 rpm、500 rpm 刻み）× スロットル開度 21 行（0〜100%、5% 刻み） |
| 値の表し方 | 燃料噴射の補正率（−40〜+40%）に **100 を足した値（60〜140）** で記録する。`0` はレブリミットより上の領域 |
| .fmp | 1 行が回転数の列 1 本分で、カンマ区切りの整数 21 個が並ぶ。これが 30 行あるテキスト |
| マップの選択 | 本体の 4 ビット DIP スイッチで選ぶ。マップ番号 = 1 + (DIP1×8 + DIP2×4 + DIP3×2 + DIP4×1)。**MAP16（全部 ON）がユーザーオリジナルマップ** |
| 純正ケーブル | USB → CP210x と思われる箱 → 8 芯ケーブル → 2 列 × 4 の 8 極防水カプラ。通信に使うのは TX、RX、GND のはずだが、8 極すべてに端子が入っている |

| 表記 | 意味 |
